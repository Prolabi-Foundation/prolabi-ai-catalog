# Security policy

Do not report suspected key exposure, signature bypasses, catalog tampering, or credential leaks in a public issue. Use GitHub's private vulnerability reporting for this repository or contact the Prolabi Foundation through a private organizational channel.

Never attach private signing keys, provider credentials, unredacted prompts, provider responses, or paid-smoke evidence containing remote request identifiers. If secret material is committed, treat it as compromised and rotate it; deleting Git history is not sufficient remediation.
